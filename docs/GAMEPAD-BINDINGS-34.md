# 手柄键位方案（第一版）

> 2026-11-15 / 依据：你给的《键位设计思路》（2.5D + 俯视 45°）+ 客户端原生手柄表
> 工程：`/mnt/e/godot_proj/dnf_like` · 代码：`core/input/gamepad_keys.gd`（`GamepadKeys`）

## 0. 一句话

手柄和键盘**共用同一套技能/角色规则**（技能槽 1–12、药水槽 1–2、攻击/跳跃/闪避语义不变），
只是换一套输入层。两套预设可切换：**设计稿**（按你的思路）和**客户端原生**（DNF 自己的手柄表，用来对照）。

## 1. 你给的设计 → 落地成什么

| 你的要求 | 落地 |
|---|---|
| 2.5D：面键 4 个 = 第一排技能，按住左肩键再按面键 = 第二排 | `A/B/X/Y` = 技能槽 1–4；`LB + A/B/X/Y` = 技能槽 5–8 |
| 2.5D：可选第三排（左扳机修饰），默认不开 | `LT + A/B/X/Y` = 技能槽 9–12，设置窗口里一个勾「启用第三排」 |
| 右肩键/右扳机留给高频动作 | `RT` = 普攻，`RB` = 闪避 |
| 十字键放药水/道具/切目标 | `▲▼` = 药水 1/2，`◀▶` = 切目标 |
| 左摇杆移动、右摇杆瞄准/选目标 | 左摇杆挂到 `move_*` 语义动作；右摇杆 → `pad_look_*`（2 个方向轴，给瞄准/镜头用） |
| 俯视 45°：技能优先直按、少用修饰键 | 技能槽 5–8 改到**十字键直按**（`▲▼◀▶`），药水/目标退到 `LB + 十字键` |
| 俯视 45°：扳机负责普攻 | `RT` = 普攻，`RB` = 闪避（两种模式一致） |

## 2. 两套预设

### A. 设计稿（默认）

| 动作 | 2.5D | 俯视 45° |
|---|---|---|
| 技能槽 1–4 | `Ⓐ Ⓑ Ⓧ Ⓨ` | `Ⓐ Ⓑ Ⓧ Ⓨ` |
| 技能槽 5–8 | `LB + Ⓐ Ⓑ Ⓧ Ⓨ` | `▲ ▼ ◀ ▶`（直按，不用修饰） |
| 技能槽 9–12（可选） | `LT + Ⓐ Ⓑ Ⓧ Ⓨ` | `LT + Ⓐ Ⓑ Ⓧ Ⓨ` |
| 普通攻击 | `RT` | `RT` |
| 闪避 | `RB` | `RB` |
| 药水 1 / 2 | `▲` / `▼` | `LB + ▲` / `LB + ▼` |
| 切目标 | `◀` / `▶` | `LB + ◀` / `LB + ▶` |
| 菜单 / 关闭 | `START` / `BACK` | 同左 |
| 移动 / 瞄准 | 左摇杆 / 右摇杆 | 同左 |

### B. 客户端原生（对照用，从 PVF 解出）

`clientonly/gamepad/gamepadhotkeyinfo.co` 里每个动作都带 `[default] joy_*` 字段，实测（66 条）：

| 动作 | 客户端原生 |
|---|---|
| 移动 | 左摇杆（`joy_laxis_*`） |
| 普通攻击 `I05` | `Ⓐ` |
| 跳跃 `I06` | `Ⓑ` |
| 技能 `I07` | `Ⓧ` |
| 技能2 `I08` | `Ⓨ` |
| 物品 1–4 `I33–I36` | 十字键 ▲▶▼◀ |
| 技能 1–4 `I21–I24` | `Ⓧ Ⓨ Ⓑ Ⓐ` |
| 技能 5 / 6 `I25`/`I26` | `RB` / `RT` |
| 组合键 1 / 2 `K16`/`K17` | `LB` / `LT`（就是修饰键） |
| 关闭全部菜单 `I49` | `BACK` |
| 鼠标切换 `K18` | `START` |
| 鼠标模拟 | 左摇杆移光标、右摇杆滚轮、`Ⓐ`=左键、`Ⓑ`=右键 |

> 注意：客户端把**技能 5/6 放在 RB/RT**，而你的方案把 RB/RT 留给闪避和普攻 —— 这是有意分歧，
> 所以做成两套预设而不是改客户端那套。切到「客户端原生」就能拿 DNF 的手感做 A/B 对比。

## 3. 代码怎么用

```gdscript
GamepadKeys.install()                       # 开局一次（会挂到 DnfKeys.watch，改键盘不会冲掉手柄事件）
GamepadKeys.set_preset(GamepadKeys.PRESET_DESIGN)   # 或 PRESET_DNF
GamepadKeys.set_mode(GamepadKeys.MODE_TOPDOWN)      # 或 MODE_2_5D
GamepadKeys.set_extra_row(true)             # 第三排（LT 修饰）

# 每帧读一次（普攻/闪避/跳跃已经挂在 InputMap 上，玩家逻辑不用改）
var it := GamepadKeys.read()
#   it.attack  普攻（常按）
#   it.dodge / it.jump   边沿
#   it.skill       -1 或 0..11 技能槽
#   it.consumable  -1 或 0..3 药水/道具槽
#   it.target      -1 / 0 / 1 切目标
#   it.menu / it.close
#   it.look        Vector2 右摇杆
```

- 技能槽号与 HUD 的 `set_skill(i, ...)` / `player.hotbar_skill(i)` 是同一套编号，不需要换算。
- 摇杆移动是**直接把手柄轴事件挂到 `move_left/right/up/down`** 上的，所以 `player.gd` 一行没改。
- HUD 会自动切换：检测到手柄（或 `SF85_HUD_PAD=1`）时，键帽变手柄字形、技能栏从 6×2 变 4×2（4×3）。

## 7. 已知缺口

1. **没有实体手柄实测**：本机 `Input.get_connected_joypads()` 为空，所有验证都是「绑定结构 + 布局表 + 截图」级别的，手感必须你上手试。
2. 右摇杆只暴露了 `look` 向量，还没接到瞄准/镜头/选目标的具体逻辑（等俯视模式做出来再定）。
3. 切目标目前是「轮转最近怪物」，没有锁定框、没有目标高亮；锁定逻辑要等战斗系统。
4. 手柄改键（自定义映射）没做，只有预设切换。
5. 振动/扳机力反馈、长按/双击等高级输入没做。
