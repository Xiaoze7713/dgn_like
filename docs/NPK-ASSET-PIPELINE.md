# DNF 的 2D 资产是怎么做出来的

> 写给「想自己独立做这类资产」的人。结论先行：**alpha 是画出来的，不是电脑抠的；大图 atlas 才是电脑打包的；
> 你看到的「散」，是因为 DNF 的「整体」= 多个 IMG 图层 + 一个 ANI 时间轴，而 NPK 里只存图层。**

---

## 1. 三个层级：PVF / NPK / IMG

| 层 | 是什么 | 里面有什么 |
| --- | --- | --- |
| PVF（Script.pvf） | 游戏逻辑与配置 | `.ani` 时间轴、`.chr`/`.equ` 角色与装备配置、`.act` 动作脚本、技能数据 |
| NPK（ImagePacks2） | 美术资源包 | 一堆 `.img`（也有 ogg），按目录平铺，**没有「角色」这个概念** |
| IMG | **一个图层**的帧序列 | 每帧的像素 + x/y 偏移 + 画布尺寸 + 压缩格式；v5 还有共享大图和裁剪矩形 |

关键点：**一个 IMG ≠ 一个角色，也 ≠ 一个动作。它只是一层。** 一个「站立」的剑魂，至少是：

```
身体(skin) + 上衣 + 下装 + 鞋 + 腰带 + 项链 + 头发 + 帽子 + 武器 + 光环/特效
   ↑ 每一样都是一个独立 IMG，各自一套帧（同一动作通常帧数相同、顺序相同）
```

游戏在运行时把这 10 个 IMG 按**同一个帧号**叠在同一个原点上，再按 `.ani` 里每帧的延迟播。
所以你单看一个 NPK，永远看不到「整体」——整体是运行时拼出来的。

## 2. 「抠图」到底是谁做的

**不是电脑自动抠的。** 具体分三种：

1. **常规角色/怪物/UI**：原画师在透明画布上逐帧画（或 3D 渲染后修），alpha 通道是画的一部分。
   边缘的半透明、发丝、渐变都是美术手工处理的，文件里没有绿幕/黑底 matte 可抠。
2. **加法特效**（红色系统字、发光、火焰）：画在黑底上，游戏里用**加法混合**画——黑 = 加 0，自然就“透明”了。
   这类图你直接看是黑块，不是抠坏了；本工具预览看到的黑块就是字节原样。
3. **atlas 打包**：这个才是电脑做的。v5 把很多帧的矩形自动塞进一张 504×240 的 DDS，
   帧记录里存 `left/up/right/down` 四个裁剪坐标。打包是工具算的，**画还是人画的**。

## 3. 对齐是怎么保证的（你能照抄的部分）

DNF 的约定非常朴素，也很好抄：

- **统一画布**：同一个动作的所有帧用同一个 `frameWidth × frameHeight`（角色常见 500×500），
  画布只是对齐框，不参与绘制。
- **统一原点**：每帧记一个 `(x, y)`，是这帧相对角色原点的偏移。脚底/重心固定在原点，
  帧里人物怎么动，靠 x/y 和像素内容表达。
- **帧序固定**：IMG 里帧就是按顺序存的，没有时间信息；时间在 ANI 里（毫秒延迟）。
- **图层同序**：装备/武器层和身体层用同样的帧号（站立第 3 帧 ↔ 上衣第 3 帧）。

> 反过来说：只要你保证「同画布 + 同原点 + 同帧序」，你的分层素材就能像 DNF 一样叠。

## 4. 自己独立做一套的推荐管线

1. **拆件**：身体、头发、上衣、武器、特效各一层；每层导出成「每帧一张 PNG，透明底」。
2. **定基准**：所有层用同一张画布尺寸；在画布上标一个固定原点（比如脚底中心），
   每帧记录相对原点的偏移（就是 DNF 的 x/y）。
3. **导成表**：把每层打包成精灵表 + JSON（本工具「拼装 · 导出」就是干这个），JSON 里带
   每帧的格内坐标、原点、层信息。Godot 里一层一个 `AnimatedSprite2D`（或 `Sprite2D` + `AnimationPlayer`），
   所有层共用帧号推进。
4. **时间轴**：自己定一个帧延迟表（DNF 的 ANI 等价物）：帧号 → 毫秒、位移、判定盒、音效事件。
   可以先从固定 fps 开始，动作游戏再补逐帧延迟。
5. **混合模式**：加法层单独标记（Godot 里 `CanvasItemMaterial` 的 blend mode = add）。
6. **打包**：自己项目不必学 DDS/atlas，PNG 精灵表就够；要省显存再用 Godot 的 AtlasTexture。

## 5. 用本工具把现有素材还原成「整体」

1. 打开 NPK（或整个 ImagePacks2 文件夹），选中**身体层**（如 `.../avatar/skin/sg_body0000.img`）。
2. 切到 **拼装 · 导出**：当前条目自动成为底层。
3. 「＋ 从本包添加」→ 选上衣/武器/特效层；「＋ 从文件添加」可以加别的包里的 `.img`。
4. 拖动帧滑条/播放，检查各层是否对齐（x/y 已自动叠加）。
5. 「导出精灵表 PNG + JSON」→ 拿去 Godot；「导出动图 APNG」→ 直接看整段效果（带透明）。

> 注意：装备层和身体层的帧数可能不同（有的装备动作少几帧）。工具里每层按自己的帧数循环；
> 要严格「第 N 帧对应第 N 帧」还得靠 ANI，本工具暂未接。

## 6. 已知边界

- ANI 时间轴（逐帧延迟、事件、判定盒）还没接进查看器；目前拼装用的是固定 fps。
- 加法混合层在预览里显示为黑底，这是正确的原始字节。
- v5 的 atlas 是「打包结果」，不是「美术源文件」；想改图要改帧，再自己重新打包。
