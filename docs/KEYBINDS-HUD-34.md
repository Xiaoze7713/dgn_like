## 2. 键位数据来源（可复现）

```bash
python3 tools/extract_dnf_hotkeys.py        # 重新生成 data/dnf_hotkeys.json
```

客户端 `clientonly/hotkeysystem_ver3.co` 每条记录 = 名称 + 动作 id + 分类 + 左右列 + 键位（空）+ 类型。
按 id 去重后 **123 个动作**：系统 59 / 角色 27 / 技能 27 / 聊天快捷键 10 —— 正好对应客户端
「键盘设置窗口」的四个页签。**默认键位不在数据里**（在 exe 里硬编码），所以本方案是自拟的临时绑定，
贴着 DNF 的肌肉记忆：方向键移动、X 普攻、C 跳跃、Z 技能、空格技能2、A S D F G H 技能 1–6、
Q W E R T Y 扩展技能 1–6、1–6 物品快捷键。

## 3. 怎么用

| 操作 | 说明 |
|---|---|
| `F9` | 打开键盘设置窗口（也可以点 HUD 右侧「键位」按钮） |
| 点键帽 | 进入录制：按任意键确认、`Esc` 取消、`Delete` 清空 |
| 恢复默认 | 设置窗口底部按钮，回到本文档的临时方案 |
| 存盘 | 改键后自动写 `user://keybindings.cfg`，下次启动读回 |

代码里查键位一律走 id，不再写死按键：

```gdscript
DnfKeys.install()                 # 建 InputMap 动作（幂等），一般在开局调一次
if DnfKeys.is_just_pressed("I05"): ...      # 按 DNF 动作 id
if DnfKeys.just_pressed("attack"): ...      # 按语义动作名（player.gd 里的写法）
DnfKeys.key_label("I21")          # → "A"（改键后自动变）
DnfKeys.set_key("I21", "K"); DnfKeys.save()
```

语义动作映射（`DnfKeys.SEMANTIC`）：`move_up/down/left/right`、`attack`、`jump`、`skill`、`skill2`
分别指向 I01–I08，`player.gd` 完全没改逻辑，只是按键来源换成了这套表。

## 4. HUD 版式（对应客户端截图）

- **左**：2 列 × 3 行消耗品格，格内左下角是物品快捷键 `1`–`6`，右下角是数量。
- **中**：6 × 2 技能格；上排 `A S D F G H`（技能快捷键 1–6），下排 `Q W E R T Y`（扩展 1–6）；
  键帽文字随改键实时变化，冷却时压暗并显示剩余秒数。
- **中左 / 中右**：圆形 HP / MP 球（100% 时整环，文字显示百分比）。
- **右**：功能按钮 2 行——`背包` / `键位` / `地图`、`商城` / `菜单`（悬停出提示，地图与商城当前是占位提示）。
- 整条 bar 宽 860、高 118、贴底 6px，随窗口宽度居中。

HUD 对外接口：

```gdscript
hud_bottom.setup(player, self)
hud_bottom.set_skill(0, icon, "上挑", 5.0)   # 图标可空，空时用技能名前两字
hud_bottom.set_skill_cd(0, 1.4, 5.0)         # 每帧刷冷却
hud_bottom.set_consumable(0, icon, 217, "红色小晶块")
hud_bottom.toast("提示文字")
# 信号：consumable_used(index) / skill_used(index) / button_pressed(id)
```

## 5.5 手柄

手柄走另一套布局（同一套技能槽编号），见 `docs/GAMEPAD-BINDINGS-34.md`：
2.5D 是「面键 4 + LB 修饰 4（+LT 可选 4）」，俯视 45° 是「面键 4 + 十字键 4」，`RT` 普攻、`RB` 闪避。
接上手柄后底部 HUD 会自动换成手柄字形与 4 列布局。

## 6. 已知缺口（下一步）

1. **消耗品栏没接背包**：格子能点、能显示数量，但还没和 `ItemDB`/背包联动（`_on_consumable_used` 现在只弹提示）。
2. **技能槽只有 0 号有技能**（现有的「上挑」）；1–11 号槽按键会提示「还没装配技能」，等技能系统接上后填 `set_skill` 即可。
3. **右侧功能按钮**：`背包` 已接 `UIRoot.toggle_inventory()`，`键位` 已接设置窗口；`地图` / `商城` / `菜单` 目前只弹提示。
4. **手柄**：按你的要求先不做，但动作表/分类已经就位（客户端的 `gamepad/gamepadhotkeyinfo.co` 也在 PVF 里，之后要做可以直接取）。
5. `I11 技能栏` 默认留空 —— 本工程把 `K` 留给了金库窗口（`sf85_warehouse` 动作）。
