# 词缀与属性上限

> **结论**：词缀系统要分成两套**互相独立**的规则：
> **生成规则**决定「这件装备能出什么、出几条」；**生效规则**决定「全身累计后，超出上限的部分怎么处理」。
>
> 不能因为玩家暴击率已经堆到 120%，就不让副本掉暴击率戒指。装备仍然可以掉，只是超出部分没收益。
> 具体部位配额、数值区间和上限还没全部锁定，这篇先把分类和规则骨架定下来。

## 一、两套规则，不要混

| 规则 | 管什么 | 例子 |
|---|---|---|
| 词缀生成 | 部位限制、词缀池、数量、数值 | 上衣不出暴击；戒指最多 4 条；同类属性最多 1 条 |
| 属性生效 | 属性适配、全局上限、递减 | 暴击率 120% → 只有 100% 生效 |

这两套规则独立的好处：

- 掉落始终合法，不会出现「因为玩家属性满了，所以这件装备不该掉」。
- 装备对别人仍然可能有价值，交易和跨职业才有空间。
- 数值上限只影响收益，不影响掉落体验。

## 二、词缀分类：两层

用户明确要的是**两层**：大类用于归纳，小类用于职业定制。

### 第一层：大类

| 大类 | 包含 | 主要职责 |
|---|---|---|
| 基础属性池 | 力量、敏捷、智力、体质 | 职业基础成长 |
| 攻击属性池 | 攻击力、物理伤害、元素伤害 | 基础输出 |
| 暴击属性池 | 暴击率、暴击伤害 | 暴击判定与倍率 |
| 伤害增幅池 | 全局增伤、技能增伤、条件增伤 | 统一加法区 |
| 速度属性池 | 攻击速度、施法速度、移动速度 | 动作频率与时间 |
| 防御属性池 | 护甲、伤害减免、护盾强度 | 承伤 |
| 生存属性池 | 生命、生命恢复、吸血 | 续航 |
| 抗性属性池 | 物理、火、冰、雷、毒、灵能抗性 | 按类型减伤 |
| 穿透属性池 | 护盾穿透、护甲穿透、元素穿透 | 目标防御计算 |
| 技能属性池 | 技能等级、冷却、范围、持续时间 | 技能成长 |
| 资源属性池 | 资源上限、恢复、消耗降低 | 职业资源 |
| 召唤物属性池 | 召唤物伤害、生命、攻速、数量 | 召唤体系 |
| 异常状态池 | 概率、持续时间、效果强度 | 异常机制 |
| 特殊机制池 | 投射物、触发、额外目标 | 特殊构筑 |

### 第二层：职业 / 专精小类

大类是全局稳定的；小类按职业定制，但**不要另建一套独立系统**，仍然挂在大类下面。

| 大类 | 通用 | 剑修 | 术修 | 御灵 |
|---|---|---|---|---|
| 伤害增幅 | 攻击伤害 | 剑气伤害、飞剑伤害 | 元素伤害、雷法伤害 | 召唤物伤害 |
| 技能 | 技能冷却 | 飞剑技能等级 | 雷法技能等级 | 灵兽技能等级 |
| 资源 | 灵力恢复 | 剑意恢复 | 法力恢复 | 契约恢复 |
| 特殊机制 | 触发概率 | 飞剑穿透 | 元素扩散 | 召唤物数量 |

生成装备时，仍然是同一套词缀系统，只是根据「当前角色」决定哪些候选词缀参与随机。

## 三、生成规则

### 1. 每件装备几条

以 **4 条随机词缀**为例（暗黑 4 式，具体数字未锁定）：

- 不是从所有属性里随机抽 4 条。
- 先由部位决定「能出哪些方向」。
- 再由分类配额决定「同类最多几条」。
- 最后 roll 数值。

### 2. 同一属性不能重复

同一件装备上，同一个具体属性最多 1 条。比如不能出现两条「暴击率」。
不同属性即使同大类，也可以同时出现（暴击率 + 暴击伤害），是否允许由更细的配额决定。

### 3. 分类配额

同一大类可以限制最多出现几条。例：

| 分类 | 单件限制（示例） |
|---|---|
| 基础属性 | 每种最多 1 条 |
| 暴击 | 每种最多 1 条，整类最多 2 条 |
| 攻击 | 每种最多 1 条 |
| 技能 | 每种最多 1 条 |
| 生存 | 每种最多 1 条 |
| 特殊 | 视词缀而定 |

### 4. 部位限制

不同部位有自己的词缀池，不是全身共享一个池。

| 部位 | 主要方向 |
|---|---|
| 头部 | 生命、防御、抗性、基础属性、冷却 |
| 护肩 | 防御、抗性、减伤、基础属性 |
| 上衣 | 生命、防御、抗性、职业相关 |
| 下装 | 生命、防御、移动、生存 |
| 腰带 | 生命、资源、恢复、抗性 |
| 鞋子 | 移速、闪避、生存、基础属性 |
| 护腕 | 攻速、暴击、技能伤害、基础属性 |
| 项链 | 暴击、冷却、资源、特殊 |
| 戒指 | 暴击、攻击、元素、技能 |
| 耳环 | 技能、资源、特殊伤害、基础属性 |
| 武器 | 基础伤害、攻速、技能机制、伤害类型 |

> 这张表是方向示意，不是最终配额。比如「上衣不出暴击」这种硬规则要先定，再谈每条几率和数值。

### 5. 词缀池分层

| 池 | 内容 |
|---|---|
| 通用池 | 生命、基础属性、防御 |
| 部位池 | 项链、戒指、鞋子等专属方向 |
| 职业池 | 特定职业可出现的属性 |
| 专精池 | 特定分支 / 技能相关 |
| 特殊池 | 极少数稀有机制 |

生成逻辑：

**部位决定基础范围 → 职业 / 专精决定额外候选 → 分类配额决定组合是否合法 → roll 数值。**

### 6. 掉落适配 ≠ 装备绑定

| 概念 | 含义 |
|---|---|
| 掉落适配 | 按当前角色的职业 / 专精选择词缀生成池 |
| 装备适配 | 装备是否允许其他职业穿戴（T0～T3） |
| 属性适配 | 词缀能否被当前角色实际使用 |

剑修刷本，掉的戒指可以带「剑气伤害」；这不代表戒指只能剑修用。术修拿到后：

- 暴击率正常生效。
- 剑气伤害没有对应机制 → 不生效。
- 力量是否生效，按职业属性规则判断。
- 灵力恢复满足条件 → 生效。

这样掉落既「跟我相关」，又保留跨职业价值。

## 四、生效规则：上限与递减

### 1. 上限是最终生效层，不是生成层

例子：全身暴击率累计 120%，设计上限 100%。

- 装备、技能、其他来源照常累计。
- 最终只有 100% 参与判定。
- 超出的 20% 不生效，或者进入递减区。

**不要因为超上限就阻止装备生成暴击率。**

### 2. 两种处理方式并存

| 方式 | 适用 | 说明 |
|---|---|---|
| 硬上限 | 暴击率、攻速、抗性 | 超过部分直接不生效 |
| 递减收益 | 移速、冷却缩减、部分防御 | 超过阈值后收益递减，仍可能有少量价值 |
| 数值预算 | 生命、攻击力 | 不设简单硬上限，靠整体数值预算控制 |

示例（未锁定）：

| 属性 | 建议 |
|---|---|
| 暴击率 | 硬上限 |
| 暴击伤害 | 递减或硬上限 |
| 攻击速度 | 硬上限 |
| 移动速度 | 递减 + 硬上限 |
| 冷却缩减 | 递减 + 硬上限 |
| 元素抗性 | 硬上限 |
| 生命 | 不设简单硬上限，用预算控制 |

### 3. 上限的边界

- 上限作用于「最终生效值」，不作用于「装备词缀是否存在」。
- 不同来源（装备、技能、威能、buff）先汇总，再套上限 / 递减。
- 上限和递减的数值要按属性分别配置，不能一个公式套所有。
- 具体阈值待战斗公式确定后再定。

## 五、速度：同一大类，但计算分开

用户明确：攻击速度和施法速度都算「速度」。

但计算上要区分：

| 速度 | 影响 |
|---|---|
| 攻击速度 | 攻击动作频率、普攻 / 攻击技能 |
| 施法速度 | 技能施放时间、读条、可缩短的前摇 |
| 移动速度 | 移动动作 |
| 持续伤害频率 | 是否加快跳伤，单独定义 |

具体技能用哪个速度，由技能标签和规则决定。例：剑阵

- 施放时有读条 → 施法速度。
- 释放后每秒攻击一次 → 是否吃攻速由技能定义。
- 每次攻击有独立前摇 → 可能吃攻速。

所以「速度」是一个词缀大类，不是「一个速度属性通吃所有动作」。

## 六、和威能的分工

| 系统 | 负责 | 不负责 |
|---|---|---|
| 随机词缀 | 数值成长、属性搭配 | 改变技能机制 |
| 威能 | 机制变化、构筑方向 | 提供大量基础数值 |
| 独特装备 | 无法复制的特殊机制 | 普通词缀替代品 |
| 套装 | 件数触发的机制组合 | 纯数值奖励 |

普通装备的价值应该由「基础属性 + 随机词缀 + 威能」共同决定，不能让威能收藏完全主导，否则普通词缀会变成无意义的填充。

## 七、首版先做什么

1. 先定大类，不急着定每条数值。
2. 先定「哪些部位绝对不能出哪些大类」。
3. 再定每件几条、同类最多几条。
4. 最后定上限 / 递减的具体阈值。

顺序反了，会在做具体装备时反复改底层分类。

## 待定

- 每件装备到底 3 条、4 条还是 5 条；不同品质是否不同。
- 每个部位允许出现哪些小类、每类最多几条。
- 职业专属词缀的占比，以及跨职业时的失效提示。
- 各属性的硬上限 / 递减阈值（要等伤害公式）。
- 基础属性（力量 / 敏捷 / 智力 / 体质）对哪些职业不生效，如何显示。
- 召唤物属性是独立池，还是并进特殊机制池（当前倾向独立池）。
- 洗练能不能改变词缀类型；如果能，是否突破部位限制。
