# 伤害与防御体系

> **状态**：这篇记录的是**讨论中形成的框架**，不是全部已锁定。
> 明确已定的部分：伤害类型与技能行为标签分离、护盾单层多抗性、破盾超负荷承载、护盾/护甲/抗性/生命分层、穿透必须区分对象。
> 仍是建议的部分：统一加法区、More 的严格限制、技能基础伤害模型、转换规则、暴击公式、具体数值。
>
> 不写实现，只写规则和推理。

## 一、先分四层，不要混成一个公式

| 层 | 管什么 | 典型问题 |
|---|---|---|
| 伤害构成 | 基础伤害、技能系数、附加伤害、伤害类型 | 这个技能打多少基础伤害？ |
| 伤害累计 | 加法区、独立乘法、暴击、条件增伤 | 装备和被动怎么放大？ |
| 防御分流 | 护盾、绕盾、装甲层、生命 | 这一下先打哪条血？ |
| 防御计算 | 护甲减伤、抗性、穿透、吸收 | 打到之后减免多少？ |

很多 ARPG 的数值失控，不是因为某一层设计得不好，而是把四层混在一起，导致「加伤」「穿盾」「减抗」互相重复计算。

## 二、三个标签维度必须分开

一项技能至少有三个维度：

| 维度 | 示例 | 决定什么 |
|---|---|---|
| 伤害类型 | 物理、火焰、冰霜、雷电、毒素、灵能 | 增伤、抗性、穿透、护盾交互 |
| 技能行为 | 近战、法术、投射物、范围、召唤物、持续 | 哪些行为标签的加成能作用 |
| 技能特征 | 剑气、飞剑、剑阵、雷法、灵兽 | 职业词缀、技能树、威能适配 |

例子：剑修放一道「雷电剑气」。

- 伤害类型：雷电。
- 技能行为：法术 / 投射物（按实际定义）。
- 技能特征：剑气、剑修技能。

它同时吃：雷电增伤、剑气增伤、投射物增伤、剑修专属威能；但**不会因为它叫剑气就自动变成物理伤害**。

这个区分也解决跨职业技能：剑修学雷法后，技能仍保留雷电类型，只是获得剑修标签或融合机制。

## 三、伤害构成

### 基础伤害从哪来：倾向技能基础伤害型

| 方案 | 规则 | 问题 |
|---|---|---|
| A 武器驱动 | 普攻和攻击技能主要按武器伤害 × 系数 | 所有玩法围绕武器，召唤、剑阵、法术容易失去独立数值空间 |
| B 技能基础伤害 | 每个技能有独立基础伤害；武器提供攻击力 / 附加伤害；技能有「附加伤害效率」 | 数值配置量更大，但六道途的差异更容易做 |

当前倾向 **B**：不同职业、不同技能可以拥有独立基础伤害模型，而不是统一依赖武器攻击力。

这与「六道途是六种战斗行为」一致：机巧的炮台、御灵的召唤物、剑修的飞剑，不应该都用同一把武器的伤害公式。

### 构成顺序

```text
技能基础伤害（技能等级 / 技能树基础强化）
  + 附加伤害（装备固定伤害、技能树附加、威能附加）
  → 伤害类型转换
  → 统一加法增伤
  → 独立乘法（More）
  → 暴击结算
  → 目标防御结算（护盾 → 本体）
```

这是职责层次，不是最终执行顺序。暴击也可以作为命中结果，在防御结算前乘一次倍率。

### 伤害转换：只转一次

保留两个概念：

| 类型 | 含义 | 例 |
|---|---|---|
| 转换 Convert | 原伤害改变类型 | 100 物理 → 100 火焰 |
| 额外获得 Gain as Extra | 原伤害保留，额外加一份新类型 | 100 物理 + 30 火焰 |

约束：

- 不允许同一份伤害反复转换，产生循环放大。
- 转换在增伤之前完成，每份基础伤害只转换一次。
- 转换后按**最终类型**参与增伤和防御计算；原始类型的增伤不再重复作用（倾向）。

## 四、伤害累计

### 1. 统一加法区

所有满足标签、目标、触发条件的普通增伤，进入**同一个加法区**：

\[
D_{\text{add}} = D \times (1 + \sum \text{Increased})
\]

例：物理剑气打精英：

| 来源 | 属性 | 数值 |
|---|---|---:|
| 装备 | 物理伤害提高 | +20% |
| 装备 | 剑气伤害提高 | +15% |
| 技能树 | 伤害提高 | +30% |
| 被动 | 对精英伤害提高 | +25% |

\[
1 + 20\% + 15\% + 30\% + 25\% = 1.9
\]

不是所有属性无条件进同一个池，而是**满足条件的那部分**进同一个池。这样暴击伤害、元素伤害、对精英伤害、剑气伤害不会因为名字不同就各自变成独立乘区。

### 2. More：保留，但严格限制

独立乘法只给少量来源：

- 独特装备的核心机制。
- 特定威能的「额外」效果。
- 专精的条件触发（如冻结目标额外受伤）。

\[
D_{\text{more}} = D \times 1.3 \times 1.2
\]

**不要让每个威能都提供 More。** 否则玩家被迫追求乘法来源，普通词缀贬值，数值也会指数膨胀。

### 3. 技能局部强化

技能树优先改变：

- 技能基础伤害。
- 技能伤害系数。
- 技能机制（段数、范围、追踪、形态）。

而不是给每个节点都加一个独立乘区。技能专精的辨识度应该来自「技能本身变了」，不是「又多了一个 ×1.2」。

### 4. 暴击

- 暴击率决定是否触发。
- 暴击倍率决定触发后提高多少。
- 暴击伤害词缀进入暴击属性池。
- 暴击倍率最终只计算一次，不因多个暴击伤害来源产生额外独立乘区。

示例：基础暴击倍率 150%，装备和技能合计 +100% 暴击伤害 → 250%，即 2.5 倍。150% 只是示例，不是最终值。

保留例外：某些技能不能暴击；某些技能有独立暴击机制；持续伤害是否暴击要单独定义，不能默认所有伤害都能暴击。

## 五、防御分层

| 防御层 | 本质 | 是否有独立耐久 | 定位 |
|---|---|---|---|
| 生命 | 最终生命 | 是 | 最后结算 |
| 护盾 | 独立吸收层 | 是 | 通用额外防御 |
| 装甲层 | 可破坏的实体防御 | 是 | 特殊敌人 / BOSS 机制 |
| 护甲减伤 | 减伤属性 | 否 | 本体物理减伤 |
| 元素抗性 | 减伤属性 | 否 | 按伤害类型 |

术语要分清：传统 ARPG 的 Armor 通常指减伤属性，不是第二条血条。要可破坏的层，就叫**装甲层**。

### 普通怪与 BOSS 的模板

- 普通怪：护盾（可选）+ 生命；护甲减伤和抗性作为属性参与计算，不额外占血条。
- 精英 / BOSS：装甲层或护盾（可选）+ 生命；可以分阶段更换防御特征。

不要给所有怪都配三条血条。

## 六、护盾：单层、多抗性、按伤害类型交互

### 已确定的结构

- **单层护盾**，不按伤害类型拆成多条血条。
- 护盾拥有**多种伤害类型的独立抗性 / 特殊交互**：可以免疫、减免、正常承受、易伤。
- 某些伤害类型可以绕过部分护盾（如毒素）。
- 绕盾伤害仍然要经过本体护甲、抗性、减伤。
- 护盾破裂时**超负荷承载**：本次攻击剩余伤害继续结算，不截断、不凭空创造。
- 护盾可以自然衰减，也可以通过技能、攻击、击杀补充；补盾不能超过上限。

### 三个独立概念

| 概念 | 含义 |
|---|---|
| 护盾抵挡率 | 这次伤害有多少分配给护盾处理 |
| 护盾抗性 | 护盾接收的部分减免多少 |
| 伤害绕盾率 | 多少伤害直接进入本体计算 |

三者可以组合，不要只用一个「护盾抗性」概括。

### 免疫 ≠ 绕过

这是最容易出漏洞的地方：

- **护盾免疫**：护盾不掉耐久，分配给护盾的伤害被抵消，**不自动转移到生命**。
- **护盾减免**：护盾承受伤害，但只损失减免后的部分。
- **伤害绕盾**：该部分直接进本体防御。
- **护盾易伤**：护盾受额外伤害，甚至触发破盾。

否则会出现「火焰免疫护盾被火焰打，反而全部穿透到生命」的荒谬结果。

### 破盾：超负荷承载

例：护盾剩 100，受到 1000 伤害。

1. 先按护盾的伤害类型规则计算这次攻击对护盾造成多少。
2. 护盾被击破。
3. 未被护盾承载的剩余伤害继续穿过护盾。
4. 穿过部分重新计算本体护甲、抗性等。
5. 不因为破盾而丢弃剩余伤害。

可以触发破盾事件（短暂失去保护、硬直、延迟恢复、破盾爆发），但这些是附加机制，不改变基础结算。

### 恢复与衰减

拆成三个参数：

| 参数 | 作用 |
|---|---|
| 护盾上限 | 最多能有多少 |
| 护盾衰减 | 随时间自然损失的速度 |
| 护盾恢复 | 自然恢复、技能、攻击、击杀等补充 |

建议：

- 生成后持续存在，缓慢衰减，不是瞬间消失。
- 持续期间可以补盾，但不能超过上限。
- 受击不必然重置全部持续时间。
- 自然衰减与主动补盾分开，避免「不断补盾 = 永久第二条血」。
- 恢复方式可以做成流派：自然恢复、延迟恢复、攻击恢复、击杀恢复、技能补盾、资源转换。

### 伤害类型与护盾交互示例

| 伤害类型 | 可能的交互 |
|---|---|
| 物理 | 穿甲、破盾、钝击 |
| 火焰 | 熔解、灼烧护盾、火焰免疫 |
| 冰霜 | 冻结护盾、降低恢复 |
| 雷电 | 传导、额外电击 |
| 毒素 | 绕盾、腐蚀装甲、生物克制 |
| 灵能 | 无视部分普通防御、对灵能护盾特殊 |

不需要全部变成基础词缀；很多是敌人设计和威能机制。

## 七、穿透：三种，不要合成一个

| 属性 | 作用对象 |
|---|---|
| 护盾穿透 / 绕盾 | 让一部分伤害直接打到本体 |
| 护甲穿透 / 破甲 | 降低本体护甲减伤，或破坏装甲层 |
| 抗性穿透 | 降低目标对应伤害类型的抗性 |

它们不能互相替代。物理穿甲不等于雷属性穿透，护盾穿透也不等于无视本体抗性。

## 八、一个完整的结算例子

敌人：

- 火焰护盾 5000，护盾火焰减免 80%。
- 本体生命 10000，本体火抗 40%。
- 本次攻击 1000 火焰伤害，护盾抵挡 80%，绕盾 20%。

| 部分 | 计算 | 结果 |
|---|---|---:|
| 护盾处理 | 800 × (1 − 80%) | 护盾损失 160 |
| 绕盾 | 200 × (1 − 40%) | 生命损失 120 |

护盾损失 160，生命损失 120。数值仅用于解释流程，不是最终参数。

## 九、哪些已定、哪些还没锁定

### 已确定

- 伤害类型与技能行为标签分离。
- 护盾单层、多伤害类型抗性。
- 护盾免疫不自动转伤到本体。
- 绕盾伤害重新计算本体防御。
- 破盾超负荷承载，剩余伤害继续结算。
- 护盾可衰减、可补充，补盾有上限。
- 装甲层只给特殊敌人 / BOSS，不做所有怪标配。
- 护盾穿透、护甲穿透、抗性穿透分开。

### 建议方案，尚未锁定

- 普通增伤统一进匹配加法区。
- More 只给少量来源。
- 技能基础伤害型（方案 B），而不是统一武器驱动。
- 转换在增伤前完成，每份伤害只转一次。
- 转换后只按最终类型增伤。
- 暴击倍率统一只算一次。

### 待定

- 技能基础伤害、武器攻击力、附加伤害、技能等级之间的具体关系。
- 护甲减伤公式（线性 / 递减 / 上限）。
- 各伤害类型的基础抗性上限、穿透上限。
- 持续伤害是否暴击、是否吃攻速。
- 护盾在玩家侧和敌人侧是否用同一套规则。
- 灵能作为独立伤害类型，还是归类为「无视部分防御」的特殊属性。
- 格挡、闪避、减伤与护盾的结算顺序。

## 十、下一步

先不要铺所有技能数值。优先确定三件事：

1. **基础伤害模型**：技能基础伤害、武器攻击力、附加伤害、技能等级怎么组合。
2. **防御公式**：护甲、抗性、穿透的具体曲线。
3. **伤害类型清单**：物理、火焰、冰霜、雷电、毒素、灵能是否都要独立抗性。

这三件确定后，词缀分类和装备数值才有稳定的落点。
