## 来源与整理说明

内容来自 2026-11 与 ChatGPT 的两轮长讨论：

1. 第一轮（装备 / 赛季 / 产品定位 / 职业聚类 / 修仙映射 / 装备数据模型）：
   <https://chatgpt.com/share/6af8ae2b-2e24-83e9-8a71-36449060382b>
   约 4.4 MB、239 个节点。
2. 第二轮（六职业收敛 / 跨职业 / 装备规则 / 词缀 / 伤害防御）：
   <https://chatgpt.com/share/6af9c0dc-3e80-83e8-9e62-61e3b8b31c4a>
   约 4.2 MB、148 个节点。

整理时做了几处口径统一，读旧稿时注意：

- **装备槽位**：讨论里先给 15 槽，项目实际落到 **16 槽**（主手、副手、备用 1、备用 2、头、肩、衣、裤、腰、鞋、腕、项链、戒指 ×2、耳环、称号）。本目录按 16 槽写，01 里保留了从 15 到 16 的差异说明。
- **职业**：14 种战斗原型是推导素材；中间收敛过 8 职业；最终定的是 **6 条道途 × 3 分支 = 18 分支，每分支 3 套构筑 = 54**。8 职业不是最终方案。
- **强化**：已确定不做装备强化等级，只保留洗练。
- **分享页配图**：原图是模型即时生成的插图，不在分享数据里；本目录的图是**重新生成的示意图**，不是原图。
- 后续关于 Codex / DSH 环境配置、工具安装的讨论没有收进来——那属于工具配置，不是游戏设计。

文中「当前口径」表示已经落到项目或已经拍板的选择；「待定」表示还没定，别当结论用。
