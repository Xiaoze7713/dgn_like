# 职业体系：14 种原型、6 个职业、18 条专精分支

> **结论**：最终采用 **6 个初始职业**，每个职业 **3 条专精分支**（预留第 4 条扩展位），
> 即 **18 条分支 × 每条 3 套构筑方向 = 54 种构筑**。
> 早期从 DNF / 暗黑提炼的 14 种原型、8 职业方案，是推导过程，不是最终口径。
> 六道途的详细设定见 [04-修仙世界观职业映射.md](04-修仙世界观职业映射.md)。

## 一、推导：14 种战斗原型

比较维度不是职业名称，而是：

- 战斗机制
- 输出方式
- 资源循环
- 操作体验
- 构筑自由度

分三类：

| 标记 | 含义 | 处理 |
|---|---|---|
| 高度重复 | 名称、技能不同，核心玩法相同 | 可以合并 |
| 部分重复 | 基础逻辑相近，但有值得保留的独特机制 | 共用框架，保留特色 |
| 独特 | 有明显不同的战斗体验 | 单独保留 |

参考范围：

- DNF：鬼剑士、格斗家、神枪手、魔法师、圣职者、暗夜使者、守护者、魔枪士、枪剑士等转职体系。
- 暗黑：D2 / D3 / D4 的代表性职业与玩法。

| # | 原型 | 主要来源 | 核心操作 | 重复度 | 建议 |
|---:|---|---|---|---|---|
| 01 | 武器大师 / 连击剑士 | DNF 剑魂、剑帝、剑影、剑宗；暗黑武僧、近战游侠 | 高攻速、多段连击、位移、取消后摇 | 高度重复 | 并入剑修 |
| 02 | 狂战士 / 重武器斗士 | DNF 狂战士、征战者、决战者；暗黑野蛮人 | 重武器、范围清怪、怒气、生命换伤害 | 高度重复 | 并入体修 |
| 03 | 格斗家 / 武术宗师 | DNF 散打、柔道、气功；暗黑武僧、魂灵师 | 近身爆发、拳脚连击、抓取控制 | 部分重复 | 并入体修 |
| 04 | 刺客 / 暗影猎手 | DNF 刺客、影舞者、忍者、特工；暗黑刺客、游侠 | 高机动、背刺、隐身、毒、陷阱 | 部分重复 | 独立为诡道 |
| 05 | 神射手 / 游侠 | DNF 漫游、弹药、旅人、猎人；暗黑恶魔猎手、亚马逊 | 移动射击、弹幕、蓄力、标记 | 高度重复 | 拆入机巧（枪械）或诡道（暗器） |
| 06 | 重炮手 / 炮术师 | DNF 枪炮师；暗黑恶魔猎手重火力流派 | 超远距离、重炮、激光、范围轰炸 | 部分重复 | 机巧·天工 |
| 07 | 元素法师 / 奥术术士 | DNF 元素师、元素爆破师、冰结师；暗黑法师、巫师 | 火冰雷、远程轰炸、元素组合 | 高度重复 | 术修 |
| 08 | 战斗法师 / 魔武双修 | DNF 战斗法师、血法师；暗黑附魔近战法师 | 魔法强化身体、近战与法术融合 | 相对独特 | 作为剑修 / 体修的跨树融合方向 |
| 09 | 召唤师 / 亡灵术士 | DNF 召唤师、死灵术士、混沌魔灵；暗黑死灵、巫医、德鲁伊召唤 | 召唤物、宠物、持续输出、军团 | 高度重复 | 御灵 |
| 10 | 傀儡师 / 机械师 | DNF 机械师、部分混沌魔灵；暗黑巫医宠物流 | 机器人、炮台、傀儡、部署物 | 部分重复 | 机巧 |
| 11 | 圣骑士 / 神圣战士 | DNF 圣骑士、驱魔师、复仇者、团长；暗黑圣骑士、圣教军 | 神圣力量、光环、盾牌、审判 | 部分重复 | 并入体修（金刚）或术修 |
| 12 | 德鲁伊 / 变形术士 | 暗黑德鲁伊 | 人/熊/狼形态切换、自然元素、召唤 | 独特 | 御灵·化形 |
| 13 | 陷阱师 / 战术控制者 | 暗黑刺客/游侠陷阱；DNF 影舞者、机械师部分技能 | 预布置陷阱、引怪、区域控制 | 独特机制 | 诡道·幻阵 |
| 14 | 时空术士 / 维度操控者 | DNF 次元行者、创造者；暗黑巫师时空技能 | 空间裂隙、时间减速、区域操控 | 独特 | 暂不作为首发职业，留作传承 / 赛季机制 |

### 几个关键判断

- **武器大师 vs 格斗家**：都是近战连击，但武器大师是「攻速 + 位移 + 取消后摇」，格斗家是「贴身 + 抓取 + 硬直」。在 2.5D 里是两种手感，最终分别落在剑修和体修。
- **刺客 vs 游侠**：暗黑刺客同时有陷阱和武术，D4 游侠近远程都行；「贴身背刺」和「移动射击」是两种操作。最终诡道保留刺客，游侠拆成机巧枪械与诡道暗器，不再单列。
- **德鲁伊**：形态切换带来不同动作模组和技能循环，归入御灵·化形，不塞进普通召唤。
- **陷阱师**：乐趣是「设计战场」，作为诡道·幻阵，不单独占职业位。
- **时空术士**：改变战场规则而不是改伤害属性，独特性高，但技能与 AI 成本高，放后续。

## 二、合并矩阵

| 原职业组合 | 重复程度 | 处理 |
|---|---|---|
| 狂战士 + 野蛮人 + 重武器战士 | 很高 | 合并为体修·破军 |
| 剑魂 + 剑帝 + 武僧 | 中高 | 合并为剑修 |
| 漫游 + 恶魔猎手 + 亚马逊 | 很高 | 拆入机巧 / 诡道 |
| 元素师 + 女巫 + 巫师 | 很高 | 合并为术修 |
| 召唤师 + 死灵法师 + 巫医 | 很高 | 合并为御灵 |
| 圣骑士 + 圣教军 | 很高 | 并入体修·金刚 |
| 刺客 + 游侠 | 中等 | 诡道保留近战，远程拆走 |
| 散打 + 武僧 | 中等 | 并入体修 |
| 战斗法师 + 魔武流 | 较低 | 跨树融合，不单列 |
| 德鲁伊 + 变形流 | 很低 | 御灵·化形 |
| 机械师 + 傀儡师 | 较低 | 机巧 |
| 次元行者 + 时空术士 | 很低 | 暂缓 |
| 柔道 + 抓取系 | 很低 | 体修·金刚 |
| 忍者 + 火焰术士 | 中等 | 诡道·影杀，不并入术修 |

> **合并不等于技能合并。** 体修的血煞和金刚可以共享角色框架、装备模型、部分动画，但保留完全不同的技能树和战斗循环。

## 三、中间方案：为什么曾经有 8 职业

在 14 原型之后、六道途之前，曾经收敛出一版 **8 职业方案**：

| 8 职业 | 定位 |
|---|---|
| 狂战士 | 近战爆发 |
| 武器大师 | 高速连击 |
| 格斗家 | 近身格斗 |
| 游侠 | 远程输出 |
| 元素法师 | 元素轰炸 |
| 召唤师 | 军团作战 |
| 暗影刺客 | 机动爆发 |
| 德鲁伊 | 形态切换 |

这一版解决的是「差异度」问题，但没解决「工作量」问题。继续往下推时发现：

- 8 个职业 × 3～4 套流派，内容量对首版过大。
- 游侠、刺客、武器大师之间仍有交叉，独立成职业会重复做动作和装备。
- 修仙世界观下，「道途」比「职业」更适合做角色基础。

于是确定：**压缩到 6 个初始职业，每个 3 条分支；分支内部再用技能树和装备形成差异。**

## 四、最终口径：6 职业 × 3 分支

| 职业 | 一句话 | 三条专精分支 | 核心资源 | 主要来源 |
|---|---|---|---|---|
| 体修 | 自己冲进去打 | 血煞、金刚、破军 | 气血 | DNF 狂战/散打/柔道；暗黑野蛮人 |
| 剑修 | 用武器与剑气连击 | 御剑、剑罡、万剑 | 剑意 | DNF 剑魂/剑帝/剑影；暗黑武僧 |
| 术修 | 操纵法则放法术 | 五行、雷法、冰魄 | 灵力 | DNF 元素/冰结/爆破；暗黑法师 |
| 御灵 | 通过其他生命单位作战 | 灵兽、亡灵、化形 | 契约 / 魂能 | DNF 召唤/死灵；暗黑死灵/德鲁伊 |
| 机巧 | 部署造物构建战场 | 灵械、傀儡、天工 | 灵械能量 | DNF 机械/枪炮；暗黑炮塔 |
| 诡道 | 用位置、状态、时机制造伤害 | 影杀、毒蛊、幻阵 | 暗影 / 印记 | DNF 刺客/影舞/忍者；暗黑陷阱 |

### 分支不是「换技能颜色」

| 职业 | 分支 | 玩法差异 |
|---|---|---|
| 体修 | 血煞 | 生命换伤害、狂暴、低血线 |
| 体修 | 金刚 | 防御、反击、震荡、抓取 |
| 体修 | 破军 | 重武器、蓄力、范围破坏 |
| 剑修 | 御剑 | 飞剑、远程剑气、剑雨 |
| 剑修 | 剑罡 | 近战连击、剑势、破防 |
| 剑修 | 万剑 | 剑阵、分身、自动追击 |
| 术修 | 五行 | 金木水火土、元素组合 |
| 术修 | 雷法 | 雷电、连锁、瞬间爆发 |
| 术修 | 冰魄 | 冻结、控制、持续伤害 |
| 御灵 | 灵兽 | 妖兽、神兽、宠物 |
| 御灵 | 亡灵 | 尸傀、魂体、幽冥 |
| 御灵 | 化形 | 兽化、变身、形态切换 |
| 机巧 | 灵械 | 机械飞剑、无人机、自动炮台 |
| 机巧 | 傀儡 | 机关傀儡、战斗机器人 |
| 机巧 | 天工 | 重炮、阵列、能量武器 |
| 诡道 | 影杀 | 潜行、背刺、瞬间爆发 |
| 诡道 | 毒蛊 | 毒素、腐蚀、持续伤害 |
| 诡道 | 幻阵 | 陷阱、幻影、空间控制 |

「3 条」是当前设计值；每条分支预留第 4 条的扩展位，但首版不铺。

## 五、技能结构：四层，不是一棵大树

| 层 | 内容 | 规则 |
|---|---|---|
| 第一层：职业基础技能 | 普攻、位移、防御、基础职业技、资源技 | 永久开放 |
| 第二层：职业通用技能 | 全职业共享的被动、资源循环、通用强化 | 本职业全分支可用 |
| 第三层：专精分支 | 御剑 / 剑罡 / 万剑这类主修方向 | 选一个主修，完整解锁 |
| 第四层：分支技能树 | 分支内的剑阵流、追踪流、爆发流等 | 用技能点形成组合 |
| 装备威能介入 | 通用 + 道统 + 传承 | 可跨分支、跨职业组合 |

重要规则：**玩家可以切换技能树，但不能无限制地同时拥有所有技能树的完整能力。**

| 权限 | 规则 |
|---|---|
| 职业基础技能 | 永久开放 |
| 主修分支 | 完整解锁 |
| 副修分支 | 允许少量技能跨分支选取 |
| 跨职业 | 只能学目标职业树的前若干层，且消耗独立拓展点 |
| 装备威能 | 允许跨分支甚至跨职业组合 |

## 六、跨职业技能：三个约束、两种形式

参考《最后纪元》的思路，不做「随便学别的职业」，而是有限开放。

### 三个约束

| 维度 | 规则 |
|---|---|
| 树深限制 | 只能学目标职业树中前若干层的技能，不能拿对方的核心专精 |
| 点数限制 | 跨职业技能消耗独立的拓展点，不挤占本职业主修 |
| 前置限制 | 必须满足技能、装备、属性或任务条件 |

示例（初始假设，待模拟）：100 点技能点中，70 点本职业 + 主修，20 点职业内副修，10 点跨职业拓展。

### 两种形式

| 形式 | 说明 | 例 |
|---|---|---|
| 原技能继承 | 拿到对方的基础技能，不拿完整专精树 | 剑修学雷法，会基础雷击，没有雷法专精 |
| 技能融合 | 通过装备或传承，把两套机制接在一起 | 剑修装机巧的自动锁定，飞剑自动追踪 |

融合形式是这套系统的价值所在：它让「跨职业」不只是多一个技能，而是形成新玩法。

## 七、54 种构筑怎么来

**6 职业 × 3 分支 × 3 套构筑方向 = 54。**

以剑修·万剑为例：

| 构筑方向 | 核心技能 | 装备驱动 |
|---|---|---|
| 剑阵流 | 万剑归宗 | 飞剑组成剑阵，持续攻击区域 |
| 追踪流 | 万剑归宗 | 飞剑追踪标记目标，集中单体 |
| 爆发流 | 万剑归宗 | 短时间大量剑影，牺牲持续 |

目前只对剑修做了完整示例；其余 17 条分支的 3 套方向还没展开。**54 是待验证的目标，不是已经设计完的内容。**

## 八、开发顺序：先做三条端到端

不建议首版直接铺 6 个职业。先选 **剑修、机巧、御灵**：

- 剑修：武器战斗、连击、飞剑。
- 机巧：部署、自动攻击、炮台。
- 御灵：召唤、持续作战、形态。

这三条分别覆盖「自己打」「造物打」「召唤物打」，最容易暴露装备、威能、AI、词缀系统的架构问题。验证通过后，再扩体修、术修、诡道。

## 九、最重要的原则：让装备决定职业还能怎么玩

**不要让职业决定玩家只能怎么玩，而应该让装备决定职业还能怎么玩。**

- 体修可以通过传承变成气血炮台。
- 剑修可以走机械剑、飞剑自动追踪。
- 术修可以通过装备变成近战冰霜法师。
- 御灵可以放弃数量，转为强化单个强力召唤兽。
- 机巧可以从炮台转为傀儡近战。
- 诡道可以从背刺转为毒雾阵地。

这样装备才真正驱动构筑探索，而不是「职业选完，玩法就定了」。

## 待定

- 每条分支的第 4 条扩展位要不要留、什么时候加。
- 18 条分支的具体资源系统、普攻节奏、位移与防御机制还没逐条设计。
- 54 种构筑目前只验证了剑修，剩下 17 条分支需要补「战斗设计矩阵」。
- 跨职业拓展点的具体数值、可学层数、哪些技能允许融合。
- 职业与种族的交互（已明确暂缓）。
