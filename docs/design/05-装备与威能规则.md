# 装备与威能规则

> **核心原则**：
> **装备是可替换的载体，威能是可积累的构筑资产，独特装备是不可复制的特殊玩法。**
>
> 换掉一件装备，不应该失去之前获得的威能。装备成长和威能收集是两条独立、又能互相促进的成长线。
>
> 这篇只写设计规则与判断，不写代码、SQL、接口实现——实现由其他人负责。数据结构只需要支撑这些规则。

## 一、四个设计对象

| 对象 | 负责 | 不负责 |
|---|---|---|
| 装备定义 | 类型、槽位、基础属性范围、词缀池、适配标签 | 玩家实际 roll 出的数值 |
| 装备实例 | 这一件装备的随机属性、原生威能、镶嵌威能、修改状态 | 静态配置 |
| 威能定义与收藏 | 威能效果、适用条件、数值区间；玩家收藏的最佳值 | 装备本身的词缀 |
| 加工 | 分解、提取、镶嵌、替换、洗练 | 强化（已取消） |

必须区分「定义」和「实例」：

- 太虚飞剑的定义是静态配置。
- 某个玩家掉落的太虚飞剑是实例，有自己的词缀、威能数值和修改记录。
- 万剑分光的定义是威能配置。
- 玩家收藏的万剑分光记录的是他见过的最高数值。

不要把定义、实例、收藏塞进同一个对象。

## 二、槽位与武器组

槽位口径见 [01-装备体系.md](01-装备体系.md)：当前 **16 槽**。

| 槽位组 | 包含 | 规则 |
|---|---|---|
| 武器 | 主手、副手 | 当前战斗武器 |
| 备用武器 | 备用 1、备用 2 | 第二套武器，切换用 |
| 防具 | 头、肩、衣、裤、腰、鞋、腕 | 常规防具 |
| 首饰 | 项链、戒指 ×2、耳环 | 常规饰品 |
| 特殊 | 称号 | 全局位 |

两条硬规则：

1. **只有当前激活的武器组参与属性、词缀和威能计算。** 备用组不叠加。
2. **双手武器占用主副手**，由武器定义声明占用关系，不是两个槽位各穿一件。

## 三、装备适配：T0～T3

装备跨职业不是「能穿 / 不能穿」两档，而是四级。

| 等级 | 范围 | 例子 | 规则 |
|---|---|---|---|
| T0 | 全职业通用 | 通用护甲、饰品、法器 | 所有职业可穿，基础属性与通用威能生效 |
| T1 | 职业通用，不限分支 | 剑修武器 | 剑修三个分支都能用 |
| T2 | 专精适配 | 机械剑、飞剑阵列、雷法法器 | 需要对应技能树才正常使用 |
| T3 | 特殊传承 | 万剑归宗传承剑、天机核心 | 限定职业、分支甚至技能节点 |

> T0～T3 只表示**适配范围**，不代表品质、装等或强度。T2 可以是普通装备，T3 也可以只是一件剧情遗物。

## 四、穿戴、基础属性、威能：三个独立判断

这是整套装备系统最关键的底层规则：

| 判断 | 含义 |
|---|---|
| CanEquip | 是否允许穿戴 |
| BaseStatsActive | 基础属性是否生效 |
| AffixActive | 特殊词缀、威能是否生效 |

一件装备可以「能穿，但只有基础属性生效」，也可以「能穿，但某几条威能因为职业 / 分支 / 技能不匹配而不生效」。

### 例子：天工·磁轨飞剑（T2）

| 角色 | 穿戴 | 基础属性 | 特殊威能 |
|---|---|---|---|
| 机械剑剑修 | 允许 | 生效 | 全部生效 |
| 普通剑修 | 条件不符 | 不生效 | 不生效 |
| 机巧师 | 条件不符 | 不生效 | 不生效 |

反过来，一件 T0 通用护甲，所有职业都能穿、基础属性都生效，但上面的「剑意恢复 +20%」只有剑修生效。

**装备可以穿，不代表每条词缀都生效。** 这能大幅提高掉落物的跨职业价值。

### 标签而不是职业 ID

装备和威能不应该硬编码「这是剑修装备」，而应该用标签匹配：

- `weapon.sword` / `weapon.mechanical_sword`
- `class.sword_cultivator` / `class.mechanist`
- `tree.sword.mechanical`
- `skill.sword.mythic_sword`
- `mechanic.projectile` / `mechanic.summon`

威能配置只声明「需要哪些标签」，不关心玩家具体是哪个职业。这样以后加分支、加职业，不用改老装备。

### 逐条效果条件

同一件装备可以同时有：

- 通用攻击力：穿上就生效。
- 飞剑自动追踪：剑修 + 机械剑专精才生效。
- 万剑归宗额外剑影：只有特定技能才生效。

不要把整件装备做成一个总开关；每条效果独立判断。客户端要显示「为什么没生效」，避免玩家刷到装备却不知道问题在哪。

## 五、品质、独特、套装

| 类型 | 规则 |
|---|---|
| 普通 / 稀有 | 提供底材、随机词缀、威能载体，是掉落主体 |
| 传奇 | 有原生威能，可提取、可替换 |
| 独特 | 天生带一个**无法拓印、不可替换**的强大固定威能；是构筑核心，不是「多一条词缀」 |
| 套装 | 本质也是威能，额外加「穿够几件」的激活条件 |

### 独特装备

- 固定威能不能提取、不能拓印、不能替换。
- 强度和机制独特，通常无法通过普通威能组合得到。
- 分解只给独特材料，不进入威能收藏。

### 套装

不要做成「2 件 +20% 伤害、4 件 +50% 伤害」的固定答案。建议三档：

- 2 件：激活一个通用或职业威能。
- 4 件：激活一个专精绑定的核心威能。
- 6 件：改变某个技能的核心机制，或提供跨道统组合。

套装威能**不是第四层**，仍属于天地 / 道统 / 传承三层，只是多了件数条件。多数套装与职业强绑定，少数跨道统。

## 六、威能：三层、获取、收藏、镶嵌

### 三层

| 层 | 适用范围 | 职责 |
|---|---|---|
| 天地通用 | 全职业 | 基础数值、通用机制 |
| 道统专属 | 同一职业的所有分支 | 职业核心机制、资源循环 |
| 传承专属 | 某个分支 / 某个技能 | 改变技能形态与输出循环 |

三层是**适用范围**，不是品质等级；第三层不一定数值更高或更稀有。

### 获取：分解 / 提取

- 普通分解：给材料。
- 威能提取：读取原生威能 → 比较收藏最佳值 → 更新收藏 → 销毁装备 → 给材料。
- 独特装备：只给独特材料，不提取固定威能。

提取必须是原子操作：不能「威能已保存但装备没销毁」，也不能反过来。

### 收藏：只存最佳值

| 情况 | 处理 |
|---|---|
| 首次获得 | 解锁收藏 |
| 新数值更高 | 更新收藏 |
| 新数值更低 | 分解材料，不覆盖 |
| 数值相同 | 不重复保存 |
| 已满值 | 仍可分解材料 |

收藏记录「见过的最高数值」，不记录每一件装备。可以额外记获取次数，用于图鉴和赛季统计。

### 同一种威能可以重复出现，但只生效最高的一份

这是后来修正过的规则：

- 允许同一种威能出现在多件装备上。
- 同时装备时，**只生效数值最高的一份**，不叠加。
- 数值相同：任选一份，结果必须一致。
- 最高那份被卸下 / 失效：自动切到剩余装备中的最高值。
- 这是全局规则，不是某几个威能的特例。

注意：**同一种威能只取最高值，不代表不同威能不能组合。** 飞剑伤害提升和飞剑数量增加可以同时生效。

### 镶嵌：可替换

| 规则 | 结论 |
|---|---|
| 来源 | 玩家威能收藏库 |
| 消耗 | 材料 + 游戏货币；威能本身不消耗 |
| 替换 | 允许；旧威能不丢失，仍在收藏库 |
| 数量 | 同一装备只保留一个主镶嵌威能 |
| 独特装备 | 禁止替换固定效果 |

镶嵌前四次校验：

1. 装备是否允许镶嵌。
2. 威能是否允许出现在该槽位。
3. 玩家是否满足职业 / 分支 / 技能条件。
4. 是否为独特装备。

切职业时不要删除已镶嵌的威能，只让它暂时失效；切回并满足条件后自动恢复。

## 七、赛季与永久：两套收藏，不互通

| 作用域 | 规则 |
|---|---|
| 当前赛季 | 同赛季所有角色共享威能收藏；不同赛季之间不直接共享 |
| 永久服 | 有自己的收藏，不直接读赛季服 |
| 赛季结束 | 按继承规则，把允许继承的内容转入永久服 |

关键判断：

- 不能让赛季角色直接使用永久服的全部威能，否则新赛季开荒失去意义。
- 继承时倾向于只继承**收藏库里的最佳数值**，不继承赛季内所有重复记录，避免永久服收藏膨胀。
- 如果赛季之间数值范围或规则变了，继承需要兼容规则。

## 八、洗练与强化

**强化体系已确定不做。** 不做装备 +1～+15、不做强化材料、不做概率失败。

保留洗练，但洗练范围还没定，需要先回答：

- 只改词缀数值，还是也允许改词缀类型？
- 能不能洗出本部位原本不会出现的词缀？
- 洗练次数是否有限制？

这个决定会直接影响毕业难度和交易价值。当前倾向：洗练只调整已有词缀的数值档位，不改变词缀类型；但这还不是最终结论。

## 九、交易：修改过就不能交易

规则的核心不是「装等」，而是**这件装备有没有被玩家改过**。

| 状态 | 能否交易 |
|---|---|
| 刚掉落、未修改 | 可以 |
| 洗练过词缀 | 不可以 |
| 镶嵌 / 替换过威能 | 不可以 |
| 人造装备 | 不可以 |
| 拾取、穿戴、放仓库 | 算未修改，不影响交易 |
| 改过又恢复原样 | 仍然不可以，避免反复操作绕过限制 |

威能收藏本身不可交易。这样既保留「刷到好东西可以换」的空间，又不会变成无限制的威能买卖。

## 十、掉落：三个独立随机过程

| 过程 | 决定 |
|---|---|
| 装备掉落 | 类型、品质、基础属性、随机词缀 |
| 威能掉落 | 通用 / 职业 / 专精，数值区间 |
| 独特掉落 | 是否出独特、哪一件 |

分开配置，否则调传奇掉率会意外影响词缀质量和威能数值。

### 难度改变分布，不垄断极品

- 普通副本也有机会出高数值。
- 高难度提高高数值概率和效率。
- 数值上限始终一致，不会「进了新难度，旧装备全失效」。
- 具体分布曲线（Beta、幂函数等）由实现方调，设计上只要求「可调偏态、难度越高越偏高」。

### 定向与防卡死

- 玩家可以通过副本 / 偏好影响装备类型，但不 100% 指定具体装备。
- 核心传奇要有相对稳定的获取渠道，避免「一件不掉，整个流派不成立」。
- 重复装备分解成材料，材料可定向兑换特定部位。
- 极品词缀仍主要靠随机，保留刷宝惊喜。

## 十一、概念数据模型

只需要这些对象，具体表结构由实现方定：

| 对象 | 关键内容 |
|---|---|
| 装备定义 | 槽位、品质、适配等级、标签、基础属性范围、词缀池、威能池、套装 ID |
| 装备实例 | 定义 ID、roll 出的基础属性、词缀、原生威能快照、镶嵌威能快照、是否被修改、是否锁定 |
| 威能定义 | 层级、激活标签、允许槽位、数值范围、效果列表 |
| 威能收藏 | 玩家 + 赛季 + 威能 ID + 最佳数值 + 获取次数 |
| 装备方案 | 当前武器组、16 槽穿戴、备用组 |
| 掉落表 | 副本 / 难度 / 装备池 / 威能池 / 独特池 |
| 套装定义 | 件数档位与对应威能 |

两个快照原则：

- 装备实例里的原生 / 镶嵌威能要保存**当时的完整快照**（ID + 数值 + 配置版本），不能加载时从收藏库实时读；收藏库以后可能更高。
- 收藏库更新不影响已掉落装备的历史记录。

## 十二、首版范围

### 阶段 1：核心闭环

- 16 槽、装备定义 / 实例。
- 基础属性 + 随机词缀。
- 普通 / 稀有 / 传奇 / 独特。
- 三层威能定义。
- 传奇掉落、提取、永久收藏、镶嵌替换。
- 同威能只取最高值。

### 阶段 2：构筑深度

- 独特装备、套装。
- 适配标签与逐条效果条件。
- 词缀洗练。
- 定向掉落、跨职业装备激活。

### 阶段 3：赛季与长期

- 赛季收藏继承。
- 装备交易。
- 稀有传承、赛季专属威能。
- 图鉴与成就。

## 待定

- 洗练的具体范围（数值 / 类型 / 次数）。
- 赛季继承是「最佳值」还是「全部记录」，以及跨版本兼容。
- 交易第一版开不开；独特装备是否拾取绑定。
- 称号给什么词缀。
- 备用武器是否所有职业都有。
- 护符 / 圣物是否以后以其他形式回来。
- 独特装备的固定威能能否被「复制 / 拓印」类机制绕过（当前结论：不能）。
