## 翻译期处理约定（本组统一口径，后续组可沿用）

1. **重复 `local` 同名变量**：若第二处位于第一处的**祖先作用域**（或同函数、或遮蔽**参数**）→ 第二处改直接赋值；**兄弟块**各自 `var` 合法，保留 `var`。
   Godot 4.7.2 实测：遮蔽参数报 `There is already a parameter named ...`，遮蔽祖先局部报 `There is already a variable named X declared in this scope`，兄弟块与前层声明不报错。
2. **遮蔽参数必须改名**：`po_atdarknessmantle` 的 `local obj` → `crackObj`（加【译注】）。这是唯一允许改标识符的情形，且只改局部变量名。
3. **与父类常量同名**的局部变量（`atmage_common` 的 `GROW_TYPE_AT_MAGE` 等）→ 加 `_local` 后缀 + 译注。
4. **与基类 `sqr_script.gd` 桩同名且签名不同** → 按 PORT-SPEC §9 加 `entry_` 前缀（本组仅 `common.gd` 两处）。只在 `sqr_globals.gd` 里有桩、不是父类成员的同名函数照原样定义。
5. **顶层可执行语句** → `func _init() -> void:`；`X <- 运行时调用()` → `var X := 0` + `_init` 里赋值。
6. **`#if(...)` 的裸块 `{ }`** → 保留为 GDScript 匿名块，**左右花括号都要写**（`sqr_check.py` 会数花括号，漏 `}` 直接报不配平）。
7. **`# 原:` 行必须放在 `##` 行之上**（`##` 是 func 上方最近的非空行，中间不能插普通 `#` 注释，否则报「上方缺少 ## 功能注释」）。
8. 函数间空两行、tab 缩进、不写 `class_name`、不手写 `xg.` 前缀（但保留 `var xg := SqrGlobals.new()`，`sqr_xref.py` 有 `if "var xg" not in text` 保护，不会重复插入）。
