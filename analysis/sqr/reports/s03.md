## 需要人看的点

1. **【需拍板】`common_header.gd` 与 `SqrConsts` 重复。** 本文件的 14 类常量（共 40 个名字）**100% 已被
   `sqr_gd/sqr_consts.gd` 收录**，而 `SqrScript extends SqrConsts`（`sqr_gd/sqr_script.gd:13`），
   在子类里再 `const` 一次会报
   `Parse Error: The member "STATE_BURSTER" already exists in parent class SqrConsts.`
   （实测 Godot 4.7.2 `--check-only`）。
   本组处理：文件头写清「常量由 `SqrConsts` 提供」，每个声明改成 `# const X := N` 的**文档形式**（值、注释全保留）。
   若项目希望这类 `*_header.nut` 仍然产出可执行常量，则应让**生成器跳过 header 文件的 .gd 产出**，
   或者让 `SqrConsts` 只做「兜底」不重复声明——**这两种都得在生成器层面统一，不宜各翻译组各改一套**。
2. **【阻塞·全项目】`printc()` 没有桩。** `sqr_script.gd` 里没有 `printc`，Godot 报
   `Parse Error: Function "printc()" not found in base self.`
   本组受影响 1 处（`po_aticefieldex.gd:62`），另有 `character/atmage/lightningwall/ap_lightningwall.gd:96,102` 同样中招；
   全项目 15 个源 `.nut` 用它。按「禁改标识符」保留原名未动，**修法：在 `SqrScript` 补一个 8 参桩即可**。
3. **【阻塞·全项目】技能脚本里的顶层常量没有落点。** `sqr_consts.gd` 只收 `dnf_enum_header.nut` + 各职业
   `*_header.nut`，**技能脚本里的顶层 `X <- v` 漏了**，导致本组 2 个文件编译不过：
   - `po_earthquakerock.gd:17,18` → `Identifier "EARTHQUAKE_ROCK_MAX" not declared in the current scope.`（=3，`character/priest/earthquake.nut:1`）
   - `po_spincutterthrow.gd:61` → `Identifier "S_SPINCUTTER_THROW" not declared in the current scope.`（=0，`character/priest/spincutter.nut:2`）
   建议把「所有 .nut 的顶层 slot」都收进 `SqrConsts`（Squirrel 本来就是全局命名空间，这类引用很多）。
4. **【阻塞·全项目】`CNSquirrelAppendage` 全局类没有提供。** 原版是引擎暴露的全局对象，翻译后无定义，
   `ap_atmage_elemental_change.gd:54` 报 `Identifier "CNSquirrelAppendage" not declared in the current scope.`
   全项目 4 个文件用到它的 5 个方法：`sq_AppendAppendage`(5 次)、`sq_GetAppendage`(2)、`sq_RemoveAppendage`(1)、
   `sq_IsAppendAppendage`(1)、`sq_AppendAppendageID`(1)。可照 `IRDSQRCharacter` 的做法，在 `SqrConsts` 里
   放一个内部类实例 `var CNSquirrelAppendage := _CNSquirrelAppendage.new()`。
5. **【已解决·记录】s01 报告里 #1「`sq_AddFunctionName` / `sq_AddEffect` 与基类桩签名冲突」在当前
   `sqr_gd/sqr_script.gd` 里已经不存在**（这两个桩已被移除），本组 4 个 `ap_*.gd` 的脚本级入口
   `func sq_AddFunctionName(appendage)` 实测可以编译；s01 的 #2「全局枚举常量没有落点」也已由
   `sqr_gd/sqr_consts.gd`（1771 个 const）解决。
6. **【GDScript 硬约束】参数遮蔽必须改名。** `ap_atmage_elemental_change.nut` 里
   `local appendage = CNSquirrelAppendage.sq_GetAppendage(...)` 与入参同名，Squirrel 允许（遮蔽），
   GDScript 直接 `Parse Error: There is already a parameter named "appendage" declared in this scope.`。
   译成 `var shieldAppendage`，并在 `# 原: ...` 保留原行、`# 【译注】` 说明「遮蔽效果不变（后续语句操作护盾附加体）」。
