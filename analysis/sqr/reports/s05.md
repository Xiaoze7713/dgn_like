## 需要人看的点

1. **【阻塞·基类缺绑定】`setCurrentAnimationFromCutomIndex` 在 `SqrScript` 里没有桩。**
   它**不是** `.nut` 里定义的函数（全库 `grep` 只有调用、没有 `function` 声明），是宿主注入的全局绑定，
   而 `sqr_gd/sqr_script.gd` 只收了 479 个 `sq_*` 前缀的名字，漏了这一个。实测报错：

   ```
   SCRIPT ERROR: Parse Error: Function "setCurrentAnimationFromCutomIndex()" not found in base self.
   ```

   受影响的不止本组：`character/atmage/elementalrain/po_elementalraincreator.gd:51`、
   `character/atmage/crystalattack/po_crystalcore.gd:23/25` 也都是裸调用同名函数。
   建议在 `sqr_script.gd` 补一个桩（不在本组范围，未改）：

   ```gdscript
   func setCurrentAnimationFromCutomIndex(_a = null, _b = null, _c = null) -> Variant:
   	return _stub("setCurrentAnimationFromCutomIndex")
   ```

   注意函数名里的 **Cutom** 是原绑定的拼写（不是 Custom），按规范未改。
2. **常量一律不落地**：12 个文件里原本有的 `const`（`PIECE_OF_ICE_CORE_STATE_STAY/DAMAGE/END`、
   `PIECE_OF_ICE_CORE_VAR_START_X/VAR_SHAKE_END_TIME`、`SUB_STATE_ICEPLATE_0/1`、
   `PEND_EX_PO_IS_MOVING/POS_X/SPEED`、`PEND_EX_MOVE_MAX`、`EARTHQUAKE_ROCK_MAX`）在 `sqr_consts.gd` 里都有，
   子类重声明会被 Godot 判 `The member "…" already exists in parent class SqrConsts.`。
   现按样例改成了注释行 `# NAME = 值：常量在基类 SqrConsts 里`（`tools/sqr_dedupe_consts.py` 的同一套规则）。
3. **交叉验证：s01/s02 报告里的两个「全项目阻塞」现在已不成立**（供整体收敛参考）
   - 他们报的 `sq_AddFunctionName` / `sq_AddEffect` 签名不匹配 → 现在基类桩已改成 16 个默认参数，
     实测 `appendage/character/ap_powerofdarkness.gd` **零错误**（本组 8 个 `ap_*.gd` 同理）。
   - 他们报的「`SKILL_*`/`STATE_*` 没有任何定义位置」→ 现在有 `sqr_gd/sqr_consts.gd`（2250 条），已解决。
4. **原脚本 bug 清单**（都已保留原逻辑 + `# 【原文 bug】` 标注）：
   - `ap_atdarknessmantle_effect.nut`：`isEnd` 恒 false，注释直接从复仇者觉醒变身拷来
     （`어벤져 각성 변신의 끝부분`），与本附加体无关。
   - `ap_atmage_iceroadcs.nut`：「宿主失减速或死亡就收尾」整段被注释掉，冰面可能一直留到超时才收。
   - `iceplate.nut`：同一作用域里 `local skill_level` 连写两次。
   - `po_aticeorbexprickle.nut`：`sq_ALPHA(255,255,255,0)` 传了 4 个参数（同库其它地方都是单参）；
     绑定名 `sq_SetCurrentAttackeHitStunTime`（Attacke 多一个 e，基类桩也是这么拼的，保留）。
   - `earthquake.nut`：`sq_binaryData_writeDword(...)` 那行注释写成「패시브 생성 간격（被动对象生成间隔）」，
     实际写的是**攻击力%**。
