## 需要人看的点 / 疑点

1. **`CNAvenger` 缺失**：`sqr_gd/character/avenger_load_state.gd:14` 用 `var CNAvenger = null` 占位。基类 `SqrConsts` 只有 `IRDSQRCharacter` / `IRDSUltimateSkill` / `CNSquirrelAppendage` 三个宿主单例。若有真实运行需求，要么在 `SqrConsts` 补 `CNAvenger` 桩，要么让宿主在实例化前注入——否则 `_init()` 一跑就 `null.pushScriptFiles()`。
2. **`getroottable()` 退化**：`po_icearea.nut` 用 `getroottable()["iceAreaRainCreatePos"] <- {}` 建**跨脚本共享**的全局表。`po_icearea.gd` 改成文件级 `const` 后语义从「运行时可变全局表」变成「编译期常量」——目前没有任何脚本改写它，功能等价；但如果后续有脚本依赖「改这一处、所有冰之领域跟着变」，就不成立了。
3. **`woodfence` 的两处原始 bug**：`SUB_STATE_FIREWALL_0` 当子状态用、`setCreatorSkillStateSkillIndex(obj, SKILL_WOODFENCE)` 传技能 ID。两者都**保留原逻辑**并标了 `# 【原文 bug】`。第二条若在真机上不崩，说明属性槽只是个 int、没人校验；但它的副作用是真实的：属性槽被写成 138 之后，其它属性技能里 `type == CREATOR_TYPE_X`（1~5）的「再按一次取消」判定**全部不再命中**，再按守护/烈焰等会重新施放而不是切换成普攻。`woodfence` 自己则没有取消逻辑，所以本文件内看不出异常。
4. **`piece_of_ice` 的除零与字面量 8**：`(hAngleRange/2)` 在 `hAngleRange == 0` 时除零（Squirrel/GDScript 都会抛或得到 inf），`startPosY` 公式写死 `8` 而非常量。都已标 bug，逻辑未改。
5. **`ap_atmage_bodyeffect` 的子层特效条件**：`if effect != GRAPHICEFFECT_LINEARDODGE` 才重设特效。结合三套参数里有两套本身就用 `LINEARDODGE`，这个条件会让**子层保持原色**。已标疑点，未改。
6. **`avenger_load_state` 的 `SPLASH`/`SLASH`**：`STATE_HIGH_SPEED_SPLASH` 与 `SKILL_HIGH_SPEED_SLASH` 拼写不一致。**已核对 `sqr_gd/sqr_consts.gd` 两个常量都存在**，所以不会解析失败，只是原作者命名笔误；`sqr_gd/character/avenger_load_state.gd:106` 的原样保留并标了 `# 【原文 bug】`。
7. **`creatormage_load_state` 的大小写路径**：`Character/CreatorMage/creatormage_header.nut` 与 `Character/CreatorMage/CreatorMage_header.nut` 同时出现，Linux 下是**两个不同文件**（Windows 下会撞成同一个）。原样保留，但移植到大小写敏感的文件系统时需要确认真实文件名。
8. **标识符未做任何改动**：本组 12 个 .gd 的标识符 / 字符串 / 数字 / 循环边界全部与源码一致（唯一动过的只是 `sqr_gd/character/atmage/icearea/po_icearea.gd:94` 一行**译注文字**里冰雨对象名的笔误 `po_po_ATIceAreaIceRain` → `po_ATIceAreaIceRain`，不影响代码）。`sq_SendCreatePassiveObjectPacket(obj, 24226, 0, x, y, 250, ENUM_DIRECTION_NEUTRAL)` 这一行按原样保留。
9. **约定内的写法**：`onAfterAttack_*` 原返回 `1`/`0`（不是 bool）→ 一律用 `-> Variant`；同一函数内重复 `local skill_level` 的第二处改成直接赋值（`creatorice` 等）；`local var = obj.getVar()` 因 `var` 是 GDScript 关键字改名 `sq_var`——本组出现在 `sqr_gd/character/atmage/icearea/po_icearea.gd:49`（`setCustomData_po_ATIceArea` 里，原脚本行是 `local var = obj.getVar();`，已用 `# 原:` 保留该行）。
10. **死代码保留**：`checkCommandEnable_*` 里的 `skill_level`、`piece_of_ice.onProc` 里的 `substate`、`jump_attack` 里的 `attackIndex` 均只取不用，按规范**未删**，只在注释里点明。
