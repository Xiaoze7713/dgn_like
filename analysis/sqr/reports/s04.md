## 需要人看的点（疑点 / 原脚本 bug 汇总）

1. **小写错拼的引擎绑定**（保留原样，已各自标注）：
   `po_ripperexplosion.nut` 的 `sq_isMyControlObject` / `sq_setShake(obj,...)`；
   `hedgehog.nut` 全篇的 `sq_addSetStatePacket` / `sq_stopMove` / `sq_setCurrentAnimation` /
   `sq_setCurrentAttackInfo` / `sq_setAttackPowerWithPassive` / `sq_GetSTATE`；
   `avengerjump.nut` 的 `sq_getCurrentAni` / `sq_ani_IsEnd` / `sq_ani_GetCurrentFrameIndex`。
   → 移植到 GDScript 时需要绑定层同时提供大小写两套名字，否则这些调用会直接 `null` 崩。
   建议后处理脚本统一**只加 `xg.` 前缀**，不要顺手「纠正」拼写。
2. **同名变量重复 `local` 声明**（GDScript 会编译报错，已改成赋值，语义不变）：
   `po_elementalrainbigball.nut`（`mage` 声明两次）、`icefieldex.nut`（`level` 声明两次）。
3. **复制粘贴残留**：`windstorm.nut` 用了 `SUB_STATE_FIREWALL_*` 常量名；
   `ap_pushout.nut` 内层重复判断 `state == STATE_HOLD`；`po_atdarknessmantleexp.nut` 的 `flag` var 组与 `x/y/z` 全是死代码。
4. **注册了但没实现的回调**：`ap_pushout.nut` 的 `sq_AddFunctionName("onStart", "onStart_appendage_PushOut")`。
   引擎若强制要求存在会直接报错——需要人工确认是本文件漏写还是全局别处有定义。
5. **注释与代码不一致**：`icefieldex.nut` 注释「在 100,50 生成」，实际 `24237, 0, 0, 0, 0`。
6. **资源消耗缺口**：`windstorm.nut` 里 `getCreatorSkillConsumeValue` 被注释掉，只把 consume 传给 po 侧；
   若 `po_windstorm.nut` 也不扣，风暴就是免费的。`firewall.nut` 则是正常走 `useCreatorSkill` 扣的。
7. **觉醒守卫不一致**：`avengerjump.nut` 的 `onAfterSetState_*` 没有 `isAvengerAwakenning` 判断，
   未觉醒角色也会被清一次速度和位移（影响应该是 0 帧级，但确实与其余回调不一致）。
8. **空壳关键帧回调**：`po_atwatercannonexp.nut`、`po_atdarknessmantleexp.nut` 的 `onKeyFrameFlag_*`
   原脚本**没有 `return`**（别的 po 脚本都会 `return true`）。若引擎按 bool 取返回值，这里拿到的是 null——
   未做「补 return」的修正，按原样空实现并在注释里点明。
