## 疑点 / 需要人看的点

1. **`CNRDObject` 没有占位（唯一的硬伤）**。`po_aticechakramsmallicering.gd:134-135` 两处调用
   `CNRDObject.getAngleDistanceXPos(...)` / `CNRDObject.getAngleDistanceYPos(...)`（按「起始坐标 + 角度 + 半径」算位移）。
   `sqr_consts.gd` 只给 `IRDSQRCharacter / IRDSUltimateSkill / CNSquirrelAppendage / CNAvenger / IMouse` 做了占位，
   `sqr_script.gd` / `sqr_globals.gd` 里也只有 `sq_GetCNRDObjectTo*` 系列，**没有 `CNRDObject` 这个类本身**。
   单文件检查（`sqr_check.py`）不查符号，所以它是绿的；真编译会报 `Identifier "CNRDObject" not declared`。
   我**没有**在文件里自建占位：子类里加 `var CNRDObject` 会与将来基类补的成员冲突（`The member already exists in parent class`）。
   建议在生成器（`tools/sqr_consts.py` 的占位段）里补一行 `var CNRDObject = null`，并给宿主一份实现说明
   （`getAngleDistanceXPos(srcX, angle, radius, direction)` / `getAngleDistanceYPos(srcY, angle, radius, bool)`）。
   同样的坑对其它组也可能出现，值得在基类层一次性解决。
   **已实测验证**：只在临时工程 `/tmp/gs15/sqr_consts.gd` 里加 `var CNRDObject = null`（**没有动仓库里的
   `sqr_gd/sqr_consts.gd`**），重新导入后 12 个文件 **0 报错**，`po_aticechakramsmallicering.gd` 也随之通过 ——
   这一行补上，s15 就是 12/12 编译干净。
2. **`atmage_load_state.gd` 的注册语义**：`_init()` 里一条条 push，**顺序有语义**（同一 ID 后注册覆盖前者），
   宿主必须保证「加载期实例化一次、不重复实例化」。文件里 24254 的重复注册是**原文 bug**（已标注），
   如果将来要清理，去掉第 215 行那次即可，不影响 FirePillar 段。
3. **`obj.sq_setShake(obj, amp, ms)` / `obj.sq_SetShake(obj, amp, ms)` 这类「把自身再传一次」的写法**在本组普遍存在：
   `bluedragonwill.gd:129`、`elementalbuster.gd:228`、`avengerattack.gd:355/378`、`disasterex.gd:118/302`。
   原脚本如此（大小写两种拼写也并存），已加译注保留；如果宿主按 `(amplitude, duration)` 解析，多出来的第一个参数会被忽略，
   但若按位置取参会错位 —— 建议宿主实现时对 `sq_setShake` / `sq_SetShake` 兼容两种签名。
   同理 `obj.sq_setCurrentAnimation(idx)` 与 `obj.setCurrentAnimation(ani)` 两种写法并存（前者传索引、后者传动画对象），不能统一。
4. **整数/浮点拼串**：`print` / `printc` 在原版 Squirrel 里能自动把数字转字符串，GDScript 必须显式 `str()`。
