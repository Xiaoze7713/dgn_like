## 需要人看的点

1. **【阻塞·全项目】`sq_AddFunctionName` / `sq_AddEffect` 与基类桩重名，GDScript 编译不过。**
   实测（Godot 4.7.2，`--check-only`）：

   ```
   SCRIPT ERROR: Parse Error: The function signature doesn't match the parent. Parent signature is
   "sq_AddFunctionName(Variant = <default> ×8) -> Variant".
   ```

   原因：原版 Squirrel 里「脚本级入口 `sq_AddFunctionName(appendage)`」与「宿主方法 `obj.sq_AddFunctionName("名字","回调")`」
   是两个命名空间；翻成 GDScript 后同属一个类，`sqr_gd/sqr_script.gd` 已有同名 8 参桩 → 签名不匹配。
   本组受影响 3 个文件：`appendage/character/hearthings.gd`、`appendage/character/ap_powerofdarkness.gd`、
   `character/atmage/resonance/ap_atmage_element_attack_water.gd`（后者还多一个 `sq_AddEffect`）。
   **修复应在 `sqr_script.gd`（不在本组范围内，未改）**：把这两个桩改名（如 `host_sq_AddFunctionName`），
   或让引擎入口走「按名字查表」而不是继承同名方法。按 PORT-SPEC「禁改标识符」，本组保留原名未动。
   同一问题会命中**所有** `ap_*.nut` / `po_*.nut` 组，建议在统一后处理里一次性处理。
2. **【阻塞·全项目】全局枚举常量还没有落地的位置。** `SKILL_*` / `STATE_*` / `ENUM_CHARACTERJOB_MAX` 在
   `sqr_gd/` 里没有任何定义，GDScript 会在编译期报 `Identifier "..." not declared in the current scope`
   （实测 `atmage_buff.gd`）。需要先把 `dnf_enum_header.nut` 翻成常量表（或做成 autoload）。
3. **顶层语句的翻译约定需要拍板。** `loadstate.nut` 与 `character/common_load_state.nut` 是**顶层代码**
   （加载即执行）。本组按「语义等价」包进了 `func _init() -> void:`，并在文件里写了 `# 【译注】`。
   如果项目想要别的约定（如 `func load_all()` + 显式调用），这两份要跟着改。
4. **`IRDSQRCharacter` 不是 `sq_*` API**，是宿主注入的全局对象（提供 `pushScriptFiles` / `pushState`）。
   基类 `SqrScript` 里没有它，移植运行时需要单独提供一个同名全局（autoload 或 `SqrGlobals` 成员）。
5. **`character/priest/hearthings.nut` 是 0 字节**（`ls -la` 确认，非转码失败）。若期望这里有逻辑，
   应回到原始 PVF 再抽一次；本组只能交付空实现。
6. **原脚本 bug 清单（已按规范保留原逻辑并标注）**：
   - `po_powerofdarknessarrow.nut`：`obj.sq_isMyControlObject()`（小写 + 无参）、`obj.sq_setShake(obj,3,150)`（多传 obj）。
   - `po_wind_strike.nut`：`sq_SetCurrentAttacknUpForce` 拼写多一个 `n`；注意基类桩表里**也只有**错拼版本，
     说明脚本侧一直这么调 —— 移植时应提供正确名 `sq_SetCurrentAttackUpForce` 并保留错拼别名。
   - `appendage/character/hearthings.nut`：注册名 `"hearthings"` 配 `proc_appendage_priest_scythe_mastery`（无关函数），
     且整行被注释，等于从未生效。
   - `loadstate.nut`：`CreatorMage_load_state.nut` 那行注释仍写着「남법사（男法师）」，复制粘贴未改。
   - 多份 `po_*.nut` / `ap_*.nut` 里有「取了不用的局部变量」（`state`/`substate`/`frmIndex`/`obj` 等），
     均为原脚本死代码，保留并用 `# 【译注】` 说明。
