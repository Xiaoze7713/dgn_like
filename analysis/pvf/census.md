## 2. 三类编码占比（三档合计）

- Document（节点树，即「文本 DSL 的二进制形态」）：**882,508**
- 二进制动画 `.ani`：**2,036,766**
- 纯文本（`.nut` Squirrel / `.lua` / `.str`）：**4,742**
- 其他二进制：3

## 3. 值得注意的点

1. **`.nut`（Squirrel 技能逻辑）与 `.lua`（怪物 AI 脚本）都是明文源码**，逻辑层不需要反编译。
2. `.als` 是 Document（`[use animation]` 列表），常与同名 `.ani` 配对，是「动作 → 动画」的绑定层。
3. `.ani` 占条目数 72%，单个很小，但它是「动作」的真正载体：帧序列、碰撞盒、时序、音效。
4. 有少量命名奇怪的条目：`.ani(copy)`、`.ani(diff)`、`.gdata` —— 统计时不要按后缀做硬白名单。
5. 三档后缀种类 73~92，sf85（老版本）缺约 20 种新后缀，说明数据结构在版本间是**增量演进**的。
